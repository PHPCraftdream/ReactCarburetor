## Decisions

- **Selective `"use client"`.** Components, context and hooks carry it; stores and caches stay
  server-importable and the barrels have none. Rejected: marking everything, which would make
  `new Carburetor()` a client reference on the server.
- **Store members are prototype methods.** This is a breaking change for callers who detach a
  method without binding it. Chosen because method overrides were silently ignored. Only
  detached callbacks stay bound: the write recorder, and Computed's invalidation edges and
  settlement.
- **A computed's result stays live** (documented), and its cost is fixed with an O(depth)
  `extend`. Rejected: detaching computed results.
- **`subscribe` adopts its read set**, so `addPath` decides from index state rather than Set
  membership. `watch` copies.
- **`connect()` is documented as the default read**; `useCarburetor` is for dynamic sources.
