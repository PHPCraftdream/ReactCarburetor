## Decisions

- Скоуп `@react-carburetor`, все 10 пакетов, библиотека называется `core` (выбор пользователя), а не оставить имена без скоупа.
- Каталог пакета = имя без скоупа (`npm/lint`, `npm/lint-<платформа>`), короткие имена артефактов CI, потому что `/` в имени артефакта недопустим.
- Ссылка на `esnext.disposable` сохраняется в декларациях через `preserve="true"`, а не заменяется своим типом `Symbol.dispose`.
- Типы `ICarburetorProviderProps`, `ICarburetorChildScopeProps`, `TResourceSelect`, `TUpdateTraceListener` пока не экспортируются: расширение публичного API вне релиза 0.1.0 без решения пользователя.
- Тесты агентов принимаются только после эмпирического прогона в CI с покрытием; встроенный вердикт ревьюера rush не считается доказательством.
- Слияние в `master` и публикация — только по явному разрешению пользователя; реальный `Release` не запущен.
