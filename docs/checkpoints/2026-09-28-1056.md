## Decisions

- **Structural cache redesign over the two-line mitigation.** Chose a per-tree
  `WeakMap<source, {path, proxy}>` ephemeron cache over an early return in `retire()`, because
  correctness already rested on source identity and the ledger only served memory. Rejected:
  keeping the ledger and its `WeakRef` floor.
- **Remove the instance Proxy (user decision).** `render` is now a non-configurable own
  accessor, so a class field throws a `TypeError`, and the lint rule gives the actionable
  message. Rejected: a configurable accessor plus late detection, which would run the first
  render untracked.
- **Breaking API changes at 0.1.0 without a version bump (user decision).** Internals are no
  longer exported, `useEffect(name, cb, deps)`, `watch(cb, reads?)`, a duplicate token name is
  reported instead of thrown, and `IResourceSource` gained key-based methods.
- **Kept `engines.node >=14.6.0`.** The agent had removed it, but the build emits `??`, so the
  floor is still needed.
- **Interop default comparator.** It is `sameSelection` and runs against the live result before
  detaching. Rejected: passing live proxies to a custom `isEqual`.
