## Decisions

- Store disposal flushes persist synchronously (no option); throttle on the store clock; `waitForUpdate` timeout stays on wall time; `UpdateThrottle` stays on global timers (documented rule: the clock moves what the store owns) — per @fm/@fh consultations.

- String literals are not moved into constants (no measured gain); only per-call collections and constant-built strings are hoisted, enforced by `require-hoisted-constant` (error messages/throws exempt).
- New rule ids keep protocol 2 (unreleased) and only change the contract fingerprint.
