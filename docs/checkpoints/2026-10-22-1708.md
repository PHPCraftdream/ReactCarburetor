## Decisions

- Источники без алиасов: относительные импорты в `lib/src` + условие `carburetor-source`, а не `#src/*` (бандлеры не подставляют расширения для imports-целей, rslib bundle:false не переписал бы `#`-спецификаторы в dist).
- `flush()` дописывает persist только через `flush` (отдельного `.flush()` у disposer нет); `prune`-колбэк получает третий аргумент `merge`, прежнее поведение колбэков без него сохранено.
- `onCorrupt: 'reset'` сбрасывает только нечитаемый JSON и отвергнутый стором restore; новая версия записи, сбой миграции, исключение prune-колбэка и запись из previousKeys не сбрасываются.
- Часы: настоящие таймеры при привязке часов переносятся с ПОЛНОЙ задержкой, отсчитанной на часах (вычитание реального времени давало нестабильные тесты); между часами сохраняется остаток.
- Версия бинарника линтера: номер протокола (`PROTOCOL` в Rust и `NATIVE_PROTOCOL` в плагине) + тест-отпечаток контракта вместо хэша исходников; недоступный для запуска бинарник по-прежнему даёт «could not run the native binary».
- `writeAfterRestore` по умолчанию 'changed' (пользователь: «ломающие изменения — делаем, остальное — как лучше»); partitions в этой версии не поддерживает.
- Слияние в `master` — только по явному разрешению пользователя после зелёного CI на ветке `ci/**`; коммиты — по мере выполнения задач.
