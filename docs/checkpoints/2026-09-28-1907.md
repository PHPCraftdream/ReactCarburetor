## Decisions

  everyone. Rejected: a well-known-symbol allowlist.
- **Path memo is one inline slot per handler, plus a Map only on a second key.** Rejected: a Map per
  handler, which cost +1041 B per row. Also rejected: no memo, which gave no walk speedup.

  change documented in CHANGELOG, consistent with R14-06.
- **`extend` moved from `ICarburetorSubscription` to `ICarburetor`.** This is a breaking change for
  custom subscription sources.
- **R15-02 is documented and diagnosed only.** Render-time attribution (R15-10 (1)) is left as an
  open design decision.
