### WP-3 — history and write path (P1)

Every item lands with a mechanism-counter gate that fails on the pre-change build (`perf/README.md`).

- **P1 PERF-01 = ALGO-05** — `foldDependentPatch` scans all earlier owned patches per new one with a
  closure per step: O(P²·D); head `splice` on N rows ≈ N²/2 (~5·10⁷ at 10k). Index pending owned
  targets (trie by path) → O(P·D). Gate on the owned-target axis (`history43/*` lacks it).
- **P1 ALGO-03** — with history attached, deleting a non-last dictionary key costs O(K)
  (`Object.keys` per delete) and degrades the entry to a full snapshot O(N_state); bulk deletes are
  quadratic. Position-carrying delete records → O(1) + O(K_container).
- **P2 PERF-04** — object patch endpoints cloned twice (×4 per positional row), `WeakMap` per `own()`.
- **P2 PERF-05** — reading a Date through `draft` publishes a write, refuses selection reuse, forces an
  O(state) snapshot entry.
- **P2 ALGO-04** — positional attribution for `splice`/`fill`/`copyWithin` O(N) → O(window); gates
  `array/positional@10k*`.
- **P3 ALGO-09, ALGO-10, ALGO-14, PERF-17** — fused diff overflow walk (3–4 walks → 1); LRU eviction in
  WriteLog instead of clear-all; diff-encoded history snapshots with a ring buffer; overflow allocations
  (`Error` stack capture, spread key unions).

## 4. How each package is run

Mode used in this session: executor `/wrush` (rush agent in its own worktree under `worktrees/`),
verification `gh-ci`, independent review `rush --role reviewer`.

1. Worktree per package: `git worktree add -b <wp-slug> worktrees/<wp-slug> HEAD`, seed with
   `node worktrees/r39-probes/seed.mjs <wp-slug> --links`. For WP-6 remove the `native/target`
   junction in the worktree so `cargo check`/`clippy` get their own target (`cmd //c "rmdir native\target"`).
2. Prompt: the package section of this file verbatim, the common rules
   (`.rush/stdin/rel3-fix-common.md`), and: red test before every fix, no weakening of existing tests,
   exit codes printed right after each command (no `| grep`/`| tail` masking).
3. Rounds until the built-in reviewer passes; findings it marks INFERRED are reproduced before fixing.
4. Orchestrator verification in the worktree, all of it, before any push:
   - `npm run build`, `npm run typecheck`, `npm run lint` (whole repo, 0 errors, 0 warnings in
     `lib/src` and `examples`), `node scripts/checkLayout.mjs`;
   - `npm run docs:build` twice with identical `git diff` hash, `npm run docs:check`;
   - full `npx rstest run`;
   - demo: `npx tsc --noEmit -p lib/tsconfig.json` and `cd lib && npx rsbuild build`;
   - `npm run test:consumers`;
   - `node perf/run.mjs --only <affected areas> --runs 1` for every engine package (and `hooks` when
     interop changes);
   - for WP-6 (any `native/` change), locally only `cargo check`, `cargo clippy --all-targets -- -D
     warnings` (the full CI runs exactly this) and `cargo fmt --check`; Rust builds and tests run on
     GitHub CI only (see the Rust rule below).
5. Independent `rush --role reviewer` pass on the final diff; P0–P2 go back to the agent.
6. Commit in the worktree, cherry-pick onto `master`, check the code tree matches, push, run
   `gh workflow run ci.yml --ref master`, wait for CI fast and full; remove the worktree
   (`node worktrees/r40-probes/rm-all-wt.mjs <wp-slug>`) and the branch.

Rust rule (owner, 2026-10-18), applies to the orchestrator and is copied into every sub-agent prompt:
never run Rust compilation, tests or builds (`cargo build`, `cargo test`, `cargo run`, `cargo bench`,
release builds) without an explicit request from the user. By default they run on GitHub CI. Before a
push only `cargo check`, `cargo clippy` and formatting (`cargo fmt`) are allowed locally. The rule
covers Rust only; JS/TS build, test and perf checks above are unchanged.

Lessons from this session that the checks above encode:

- Agents claim green runs that were never made (Tooling suite skipped, `grep` exit codes reported as
  test results) — verify every claim yourself.
- Never change engine code to silence a lint warning; fix the rule (`computedDependencies.ts` spread was
  reverted).
- No hardcoded engine-internal names in user-facing lint rules.
- Perf gate edits need an amendment; a raised budget is a regression until proven otherwise.
- Clippy runs only in the full CI; skipping it locally broke CI on `20625aa`.
- Do not force-push `master`: CI fast's Plan diffs against the push's `before` SHA and fails when that
  commit was rewritten away.
- Demo (`lib/src/ToDo`) is outside the root typecheck; perf scenarios call internals; the consumer
  matrix pins behaviour — all three broke CI once when skipped locally.
