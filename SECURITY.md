# Security policy

React Carburetor is preparing its first public npm release. Security reports
against the current default branch are welcome; no older-version backport
policy or response-time guarantee is established yet.

## Report a vulnerability

Email **phpcraftdream@gmail.com** with the subject `React Carburetor security`.
Please include the affected commit or version, the impact, and a minimal
reproduction or steps to reproduce. Do not put exploit details or credentials
in a public GitHub issue. We will coordinate disclosure with the reporter
before publishing a fix or advisory where practical.

For ordinary bugs and feature requests, use
[GitHub Issues](https://github.com/PHPCraftdream/ReactCarburetor/issues).
